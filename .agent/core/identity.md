# SubStellar — Project Identity & Scope

* **Nama Proyek:** SubStellar
* **Kategori:** Next-Generation Animated & Particle Subtitle Studio Desktop App
* **Repositori:** `https://github.com/SayMaven/sub-stellar`
* **Inspirasi UI:** Gatefold Foobar2000 Theme (`F:\CODE\forking\gatefold-foobar2000`)
* **Target Hardware:** Berjalan lancar di perangkat low-end (Intel HD/UHD Graphics, RAM 4 GB, CPU Dual-Core) hingga PC workstation high-end.

## Core Capabilities
1. **YouTube & Media Ingestion:** Download video (1080p/720p) & audio (M4A/Opus) terintegrasi via yt-dlp + Innertube tanpa API key.
2. **Multi-Source Synced Lyrics:** Pencarian otomatis ke LRCLIB, NetEase Cloud Music (format YRC), QQ Music, Kugou, Musixmatch.
3. **Morphological Furigana / Ruby Text:** Generator otomatis Kanji $\rightarrow$ Hiragana (Kuroshiro + Kuromoji) dengan editor koreksi manual `{漢字|かんじ}`.
4. **Real-time Particle Subtitle (PixiJS v8):** Rendering 60 FPS dengan multi-layer stroke ganda, gradien, inner/outer glow, dan partikel bintang/sparkles kosmik.
5. **Interactive Audio Waveform Timeline:** Kontrol presisi per baris dan per kata dengan Web Audio API.
6. **FFmpeg Export:** Burn-in MP4 dan Transparent Alpha Video (WebM VP9 + Alpha / Apple ProRes 4444).
